# RTC + Timer C Interrupt Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real-time clock access (read/set/BCD datetime) and a configurable Timer C periodic interrupt to the Merlin 2 emulator, exposed to the 68000 via TRAP #15 and MFP I/O registers.

**Architecture:** The ZynqMP PS has a built-in RTC at `0xFFA60000`. The emulator's MFP I/O space is extended with RTC and datetime registers. Timer C countdown uses M68K cycle counting in the main emulation loop, asserting IPL 6 (autovectored to vector 70) on expiry. The BIOS installs a default tick handler and new TRAP #15 dispatch entries.

**Tech Stack:** C (bare-metal Vitis on ARM A53), M68K assembly (vasm), Musashi 68000 emulator, Xilinx `xrtcpsu_hw.h` register definitions.

**Spec:** `docs/superpowers/specs/2026-03-19-rtc-timer-design.md`

- [ ] **Step 3: Implement Timer C countdown in `mfp_emu.c`**

Add static timer state:

```c
/* MC68901 Timer C prescaler lookup (TCDCR bits 6-4) */
static const uint32_t tc_prescaler_table[8] = {
    0, 4, 10, 16, 50, 64, 100, 200
};

/* Timer C state */
static uint32_t tc_prescaler;       /* current prescaler value (0=stopped) */
static uint8_t  tc_reload;          /* TCDR reload value */
static uint32_t tc_period_cycles;   /* CPU cycles per Timer C tick */
static int32_t  tc_accumulator;     /* cycle countdown accumulator */

#define MFP_XTAL_HZ    2457600     /* MC68901 crystal frequency */
#define CPU_CLOCK_HZ    33000000   /* M68K emulated clock */
```

Add `mfp_timer_init()` — zeros timer state.

Add recompute helper called when TCDCR or TCDR is written:

```c
static void tc_recompute(void)
{
    if (tc_prescaler == 0 || tc_reload == 0) {
        tc_period_cycles = 0;  /* stopped */
        return;
    }
    tc_period_cycles = (uint32_t)((uint64_t)CPU_CLOCK_HZ * tc_prescaler * tc_reload / MFP_XTAL_HZ);
    tc_accumulator = (int32_t)tc_period_cycles;
}
```

Update `mfp_write()` to intercept TCDCR writes (extract bits 6-4 for Timer C prescaler) and TCDR writes (update reload value), calling `tc_recompute()`.

Implement `mfp_timer_tick()`:

```c
int mfp_timer_tick(uint32_t cycles_elapsed)
{
    if (tc_period_cycles == 0)
        return 0;  /* timer stopped */
    tc_accumulator -= (int32_t)cycles_elapsed;
    if (tc_accumulator <= 0) {
        tc_accumulator += (int32_t)tc_period_cycles;
        return 1;  /* fire interrupt */
    }
    return 0;
}
```

```c

    m68k_set_irq(0);  /* deassert if no pending interrupt */
```

Note: `m68k_set_irq(0)` clears the interrupt line. The 68000 latches the interrupt on acknowledgement, so clearing after one tick cycle is correct — the handler will have started by the next `m68k_execute()` call.

- [ ] **Step 3: Implement the TRAP #15 handler bodies**

Add after the existing `.io21` handler block:

```asm
*----------------------------------------------------------------------
* TRAP #15 D0=22: Get RTC (Unix timestamp)
*   Returns: D1.L = seconds since 1970-01-01
*----------------------------------------------------------------------
.io22   MOVE.L  MFPRTC,D1
        BRA     .ioExcEnd

*----------------------------------------------------------------------
* TRAP #15 D0=23: Get datetime (BCD)
*   Returns: D1.L = YYYYMMDD (BCD), D2.L = HHMMSSwd (BCD)
*----------------------------------------------------------------------
.io23   MOVE.L  MFPDATETIME,D1
        MOVE.L  MFPDATETIME+4,D2
        BRA     .ioExcEnd

*----------------------------------------------------------------------
* TRAP #15 D0=24: Set RTC
*   D1.L = Unix timestamp to set
*----------------------------------------------------------------------
.io24   MOVE.L  D1,MFPRTC
        BRA     .ioExcEnd

*----------------------------------------------------------------------
* TRAP #15 D0=25: Get tick counter
*   Returns: D1.L = Timer C tick count since boot
*----------------------------------------------------------------------
.io25   MOVE.L  TIMER_TICK,D1
```

```c
#ifndef MERLIN2_RTC_H
#define MERLIN2_RTC_H

#include <stdint.h>

typedef struct {
    uint16_t year;
    uint8_t month, day, hour, min, sec, weekday;
} rtc_datetime_t;

/* TRAP #15 D0=22: get Unix timestamp */
uint32_t rtc_get_time(void);

/* TRAP #15 D0=23: get BCD datetime, unpacked into struct */
void rtc_get_datetime(rtc_datetime_t *dt);

/* TRAP #15 D0=24: set Unix timestamp */
void rtc_set_time(uint32_t unix_secs);

/* TRAP #15 D0=25: get Timer C tick counter */

#endif /* MERLIN2_RTC_H */
```

- [ ] **Step 2: Create `toolchain/lib/merlin2_rtc.c`**

```c
#include "merlin2_rtc.h"

#define TRAP_GET_RTC       22
#define TRAP_GET_DATETIME  23
#define TRAP_SET_RTC       24
#define TRAP_GET_TICKS     25

uint32_t rtc_get_time(void)
{
    register long d0 __asm__("d0") = TRAP_GET_RTC;
    register long d1 __asm__("d1");
    __asm__ volatile("trap #15" : "+d"(d0), "=d"(d1) : : "a0", "a1", "memory", "cc");
    return (uint32_t)d1;
}

void rtc_get_datetime(rtc_datetime_t *dt)
{
    register long d0 __asm__("d0") = TRAP_GET_DATETIME;
    register long d1 __asm__("d1");
    register long d2 __asm__("d2");
    __asm__ volatile("trap #15" : "+d"(d0), "=d"(d1), "=d"(d2) : : "a0", "a1", "memory", "cc");

    /* Unpack BCD YYYYMMDD from D1 */
    uint32_t date = (uint32_t)d1;
    dt->year  = (uint16_t)(((date >> 28) & 0xF) * 1000 + ((date >> 24) & 0xF) * 100 +
                            ((date >> 20) & 0xF) * 10   + ((date >> 16) & 0xF));
    dt->month = (uint8_t)(((date >> 12) & 0xF) * 10 + ((date >> 8) & 0xF));
    dt->day   = (uint8_t)(((date >> 4) & 0xF) * 10 + (date & 0xF));

    /* Unpack BCD HHMMSSwd from D2 */
    uint32_t time = (uint32_t)d2;
    dt->hour    = (uint8_t)(((time >> 28) & 0xF) * 10 + ((time >> 24) & 0xF));
    dt->min     = (uint8_t)(((time >> 20) & 0xF) * 10 + ((time >> 16) & 0xF));
    dt->sec     = (uint8_t)(((time >> 12) & 0xF) * 10 + ((time >> 8) & 0xF));
    dt->weekday = (uint8_t)(((time >> 4) & 0xF) * 10 + (time & 0xF));
}

void rtc_set_time(uint32_t unix_secs)
{
    register long d0 __asm__("d0") = TRAP_SET_RTC;
    register long d1 __asm__("d1") = (long)unix_secs;
    __asm__ volatile("trap #15" : "+d"(d0), "+d"(d1) : : "a0", "a1", "memory", "cc");
}

uint32_t rtc_get_ticks(void)
{
    register long d0 __asm__("d0") = TRAP_GET_TICKS;
    register long d1 __asm__("d1");
    __asm__ volatile("trap #15" : "+d"(d0), "=d"(d1) : : "a0", "a1", "memory", "cc");
    return (uint32_t)d1;
}
```
